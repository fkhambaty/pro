# Builder certification process

1. Share `work-sample-brief.md` + calendar slot for recording
2. Candidate submits pack within 48 hours of session
3. Operator scores with `rubric.md` (second reviewer for Principal)
4. Record result in `bench-tracker.csv`
5. On first paid job: collect ID/KYC for payout corridor (India first)
6. Bench target year 1: **3–5** Builders (not 50)

## Assignment rule

Clients never pick. Operator assigns by SKU tier + load. Reassign within 24 hours if a builder goes dark.
