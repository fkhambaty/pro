# Builder work-sample brief — Funberry-class

**Purpose:** Certify AI-native builders for FORMA’s internal bench. Clients never see profiles.  
**Duration:** 4 hours continuous (or 2 × 2 hours same day)  
**Allowed:** Full vibe coding (Cursor, Copilot, Claude, etc.)  
**Required:** Screen + audio recording of the full session  
**Deliverable:** Public URL + Git repo + short README (how to run, tradeoffs)

---

## The brief

Build a **mini coaching centre microsystem** inspired by real shipped products (Funberry / DataForDummies energy: complete, usable, opinionated — not a toy CRUD dump).

### Must-have (pass bar)

1. Public landing for a fictional Pune coaching centre
2. Enquiry form that stores leads (DB or equivalent)
3. Admin login
4. Students list + fee status (due/paid)
5. Record a payment (updates ledger)
6. One parent-facing view (fee status + one announcement)
7. Deployed somewhere reachable (Vercel/Railway/etc.)
8. Basic security: hashed passwords or OTP stub, no secrets in git, HTTPS

### Nice-to-have (Principal tier signals)

- CSV student import
- WhatsApp deep link on enquiry
- Mobile-polished UI
- Seed data + reset script
- Simple automated tests for fee update

### Explicitly out of scope

- Native mobile apps
- Real WhatsApp Business API
- Perfect design system
- Microservices
