# Sales & delivery playbook — first 5 packages

**Goal:** Close and deliver 5 FORMA Coaching packages in Pune before any marketplace code.  
**Primary SKU:** Growth (`COACH-GROWTH`)  
**Tools:** WhatsApp · this repo’s Canon template · Razorpay Payment Links · Figma/prototype for lock

---

## Pipeline stages

| Stage | Exit criteria |
|-------|----------------|
| Lead | Name, centre, city, student count, WhatsApp |
| Discovery | 20-min call done; SKU recommended |
| Canon draft | Screen list filled; prototype link ready |
| Canon lock | Signed PDF/ack + 40% paid |
| Build | Assigned builder; weekly update to owner |
| Staging | Owner walks checklist; 40% paid |
| Live | Domain live; 20% paid; Care starts |
| Care M1 | First month retainer collected; referral ask |

**Tracker:** copy [pipeline-tracker.csv](./pipeline-tracker.csv)

---

## Discovery call script (20 minutes)

1. “How many active students? How many batches?”
2. “How do you collect fees today? Where does money leak?”
3. “How do parents get updates — WhatsApp groups?”
4. “Do you need online payment now, or ledger + reminders is enough?” → Growth vs Pro
5. “Who will use the admin daily?”
6. Close: “We don’t build custom dreams. We install Growth / Starter / Pro. I’ll send the screen list today. You approve screens, then we build.”

**Never** ask them to write a technical brief.

---

## Closing sequence

1. Send SKU one-pager + screen list (from `ops/vertical/skus.md`)
2. Book Canon review (show clickable prototype or annotated screens)
3. Send Canon acceptance form ([canon-template.md](./canon-template.md))
4. Razorpay Payment Link for 40% deposit ([payment-milestones.md](./payment-milestones.md))
5. Kickoff WhatsApp group: Owner + FORMA operator (+ builder after assign)
