# Brand kit — Pune coaching (year 1)

## Position

**FORMA** is the name coaching owners in Pune say when they want fees, batches, and parent updates handled — without hiring developers.

Not: Upwork. Not: “AI builds your app.” Not: national software Uber.

## Promise line

Pick · Approve · Live · Care

## Voice

- Calm, direct, adult
- Short sentences
- Prices in the open
- Clear nos

Avoid: hype, emojis in brand materials, “revolutionary,” “disrupting,” developer jargon on Owner surfaces.

## Visual (catalog)

| Token | Value |
|-------|--------|
| Display | Fraunces |
| Body | Sora |
| Ink | `#0c1222` |
| Paper | `#f3f1ec` |
| Accent | `#1f4b43` (deep teal) |

## Density plan (become the local noun)

| Month | Action |
|-------|--------|
| 1–2 | 30 WhatsApp outreaches/week to Pune centres; 3 CA intros |
| 3–4 | 5 live installs; ask every Care M1 for one referral |
| 5–6 | Presence in 2 coaching-owner WhatsApp communities; one association talk |
| 7–12 | Repeat until “FORMA” is recognized in Baner / Kothrud / Hadapsar circuits |

## Geography (focus)

Primary: Baner, Balewadi, Hinjawadi, Kothrud, Karve Nagar, Hadapsar, Pimple Saudagar, FC Road / Deccan tuition belt.

Do **not** run pan-India ads in year 1.

## Proof assets

1. Catalog site (`apps/catalog`)
2. Growth demo (`apps/demo-growth`) — show on discovery calls
3. One-pager PDF from `ops/vertical/skus.md`
4. Live client Canon screenshots (after first installs)

## Messaging tests (use on calls)

- “We don’t find you a developer. We install Growth.”
- “If it’s not on the signed screens, we don’t owe it.”
- “Care is the product after go-live.”
